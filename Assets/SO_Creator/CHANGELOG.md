# Changelog

Toutes les modifications notables de ce projet seront documentées dans ce fichier.

## [1.0.0] - 2025-01-31
### Ajouté
- Création du tool `SO Creator` pour générer des `ScriptableObject` dynamiquement.
- Ajout d'un éditeur personnalisé (`EditorWindow`) avec une interface pour sélectionner et configurer un SO.
- Implémentation des attributs personnalisés :
  - `RequiredFieldAttribute` (Champ obligatoire).
  - `SliderFieldAttribute` (Slider personnalisé).
  - `ShowIfAttribute` (Affichage conditionnel).
- Système de détection automatique des `ScriptableObject` via `IncludeInSOCreator`.
- Bouton pour sauvegarder un SO en tant qu'`Asset`.
